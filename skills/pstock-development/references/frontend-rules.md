# 前端开发规则

先读需求同版本详设与 [前端架构](../../../doc/architecture/前端架构.md)。技术栈未确认时不得自行安装框架或建立可运行业务工程。

- 一个模块管理自己的 pages、components、api、state、types；简单组件不强制创建多层抽象。
- 请求使用统一客户端，避免页面直接访问外部数据源或自行附带供应商凭据。
- 页面数据来源、更新时间和缺失状态可见；研究标的与可交易标的清晰区分。
- 异步操作处理加载、错误、取消或过期响应、重复提交和离开页面后的清理；只在真实成功后展示成功。
- 准确数值使用服务端定义；前端只做展示格式和输入辅助，不能形成独立的收益或费用引擎。
- 模块之间通过公开接口协作，避免跨模块读取内部状态。shared 只放确有复用的内容。
- 新 UI 定义键盘操作、可读标签和适用屏幕范围；技术栈确定后把具体风格、组件库和类型检查命令记入工程说明。
- 定向测试覆盖真实行为。用户流程变更在服务和真实身份可用时进行浏览器验证；不可用时明确未验，不以静态截图代替实际流程。
