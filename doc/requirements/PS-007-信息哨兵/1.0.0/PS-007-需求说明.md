## 目标与场景

让我及时发现与关注对象有关的实质变化，能追溯来源、看清关联并减少重复信息。

## 主流程

采集新信息 → 识别来源和对象 → 归并重复报道 → 形成事件 → 匹配关注和关系 → 展示影响说明 → 用户已读/收藏/忽略 → 后续进展关联原事件。

入口、跨功能要求及一期容量见 [一期总览](../../V1.0.0-一期需求总览.md)。所有个人投资参数未确认时保持未设置；提到的容量/指标/时刻为产品建议值，不是已知用户事实。

## 数据对象

事件 ID、原始文档 ID、源站/作者、发布时间/采集时间、证券/行业关联、事实/推断标签、重复簇、重要性理由、进展关系、阅读状态。

对象字段为业务语义，物理表、接口路径、错误代码和索引由同版本详设确定。来源、质量与版本语义遵守 [数据架构](../../../architecture/数据架构.md)。

## 业务规则

| 规则 ID | 规则 |
|---|---|
| PS-007-R01 | 一期覆盖重点公司的公告、相关新闻、已关注行业政策与外围关联事件；优先财报/业绩变化、重大合同、分红回购、股东行为、诉讼监管等类别。事件分类不是自动投资建议。 |
| PS-007-R02 | 每条事件显示发生事项、原始出处、发布时间、涉及对象、关联理由、支持/反对证据与待观察事项；无法确认公司关联时列为待核对，不强行归属。 |
| PS-007-R03 | 同文档ID/链接或内容一致的重复采集必须合并；跨媒体转述按事件候选聚合，保留所有出处但不算多份独立证据；允许人工拆分误合并事件。 |
| PS-007-R04 | 后续进展与原事件建立关系，不能因同一公司和相近标题被删除；更正公告关联旧文档并显示更正点，旧版本可查。 |
| PS-007-R05 | 重要性按与持仓/关注关系、事件类别和实质变化说明排序，理由可见；模型标签只作辅助。阅读、收藏、忽略互不替代，忽略不删除历史。 |
| PS-007-R06 | 前期以站内消息为必交付，支持按公司、行业、类别、时间、已读筛选；外部邮件/微信渠道在用户确认前不开通，不自动发送或获取凭据。 |
| PS-007-R07 | 采集与分析任务分离；采集周期按来源窗口与允许频率确定，分析可批量执行。新闻历史不可得或某来源断流时，显示覆盖缺口与最后成功时间，不以无新事件掩盖失败。 |
| PS-007-R08 | 原文作为数据处理，不能执行其中的指令、脚本或外部操作；模型输出校验引用与身份。模型不可用时提供原文列表、确定的分类和关注匹配，影响推断标记未生成。 |
| PS-007-R09 | 全A公司公告与可得新闻支持按公司/板块/类别检索，个人提醒仍按持仓/自选/已确认关联筛选。未关注公司资料可浏览但不默认逐家公司推送；全量原始资料采集与个人提醒生成相互独立。 |

## 正常与异常结果

- PS-007-AC01：未被关注且无关联的普通新闻不占据持仓提醒；关联到关注行业的政策可进入行业视图。
- PS-007-AC02：同名公司新闻身份不明时不会自动关联证券；有效事件点击可打开对应原文。
- PS-007-AC03：同一公告被3家媒体转载只形成一个事件入口；拆分后各自来源和操作记录可查。
- PS-007-AC04：合同签订与后续终止都保留；更正后的数值不会悄悄覆盖旧报告引用。
- PS-007-AC05：用户忽略新闻后原始事件仍可检索；重大类别无持仓关系时不伪称影响本人资产。
- PS-007-AC06：未配置外部渠道也能完整使用站内消息；重试采集不会重复增加同一站内提醒。
- PS-007-AC07：快讯窗口发生断档后提示不完整；报告仍能引用完整公告源，不声称没有重大消息。
- PS-007-AC08：文章含要求泄露配置或自动发送的文字时不会触发操作；模型失败不阻断公告浏览。
- PS-007-AC09：可查看该公司已采集公告及覆盖区间；没有关注关联时不会被强行加入个人提醒，也不会因此停止资料回补。

这些结果定义预期行为，执行步骤与规则映射见 [验收标准](PS-007-验收标准.md)，当前均未运行。

## 本期边界

一期不保证全网消息覆盖、秒级预警、完整历史新闻库；不接自动下单，不把社交传闻作为确认事实。

原方案中超出本期的能力保留为后续候选，不以缩减一期方式删除历史编号。前端、后端和后台任务必须共享相同事实与规则。

## 状态、隐私与恢复

本人数据和导出需认证。新增/修改需明确反馈，失败不覆盖旧有效结果。归档与删除语义按上述规则执行；源数据修订与用户记录版本分离。日志和导出不得包含密钥，外部文本不构成可执行指令。

## 待评审与交接

本稿功能范围和产品建议值待用户确认；数据源实际覆盖、部署配置和性能目标待验证。不得把这些待确认事项改写为已通过。确认后同版本详设应逐条映射规则与验收，不得绕过需求新增自动交易、付费来源或外部通知。
