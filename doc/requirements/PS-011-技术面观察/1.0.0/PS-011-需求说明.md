## 目标与场景

让我理解价格趋势、量价变化与历史位置，技术结果可复现并可核对，不直接生成买卖指令。

## 主流程

打开公司技术页 → 选择时间范围与价格口径 → 查看日线与成交量 → 查看固定指标 → 选择基准 → 对照事件日期与原始数据。

入口、跨功能要求及一期容量见 [一期总览](../../V1.0.0-一期需求总览.md)。所有个人投资参数未确认时保持未设置；提到的容量/指标/时刻为产品建议值，不是已知用户事实。

## 数据对象

技术快照、证券 ID、交易日、价格/复权版本、指标定义版本、参数、基准、缺失状态和计算时间。

对象字段为业务语义，物理表、接口路径、错误代码和索引由同版本详设确定。来源、质量与版本语义遵守 [数据架构](../../../architecture/数据架构.md)。

## 业务规则

| 规则 ID | 规则 |
|---|---|
| PS-011-R01 | 一期仅日线；支持最近3个月、1年、3年及实际可得范围，默认1年。未复权价格用于与持仓估值核对，前复权研究曲线明确标识；切换口径重新计算，不混用。 |
| PS-011-R02 | 固定指标包括收盘价、成交量、MA5/20/60、20交易日涨跌幅、60交易日收盘价最大回撤；参数是一期开箱建议，保留计算版本，不要求用户先定义策略。 |
| PS-011-R03 | MA取最近N个有效收盘样本的算术均值；20日涨跌幅=C(t)/C(t−20)−1，需要21个有效样本。缺样本显示不足，零分母不可计算；不跨缺失数据段悄悄前向填充。 |
| PS-011-R04 | 60样本最大回撤为窗口内各日1−当日收盘/此前窗口内最高收盘的最大值，显示为非负回撤幅度，采用同一复权口径。窗口不足60不计算完整60日值。 |
| PS-011-R05 | 停牌状态单独显示，不伪造新成交；已知停牌可在图上标记空档，指标按有效交易样本计算并显示时间跨度；来源缺失不能当作停牌。 |
| PS-011-R06 | 支持一个用户选定且数据可得的市场/行业基准，以共同起点归一化比较价格变化；标明股票价格口径、基准类型及非含息收益。日期缺口不补造。 |
| PS-011-R07 | 一期仅输出可核验状态，如收盘高于MA20、均线变化和阶段回撤；不把指标组合转成上涨概率、买入评分或自动止损建议。 |
| PS-011-R08 | 公告标记按实际披露时间放置，盘后公告不得放到当天盘中已知位置；查询/计算失败保留旧有效图并标明过期。图表分页/分段加载且离开页面释放资源。 |

## 正常与异常结果

- PS-011-AC01：同一图切换口径后指标与曲线口径一致，持仓估值仍按未复权价。
- PS-011-AC02：同一数据/参数版本反复计算一致；页面能查看参数含义。
- PS-011-AC03：仅20个收盘值时MA20可算但20日涨跌幅不可算；缺中间应有行情时标记数据缺口。
- PS-011-AC04：样本[10,12,9]用于公式验算得到25%回撤；正式窗口不足60时显示样本不足。
- PS-011-AC05：停牌跨多日后用户能看出跨度，接口失败不会变成连续横盘K线。
- PS-011-AC06：不同价格量级归一化后起点一致，基准缺失时仍保留个股图并提示。
- PS-011-AC07：价格条件成立时展示数值依据，没有来源的买入/卖出命令不会出现。
- PS-011-AC08：盘后公告清楚显示盘后发布；切换股票时旧请求不能覆盖当前股票图。

这些结果定义预期行为，执行步骤与规则映射见 [验收标准](PS-011-验收标准.md)，当前均未运行。

## 本期边界

分钟/逐笔行情、画线交易、实时信号、策略回测、参数优化和组合风险模型留待后续。

原方案中超出本期的能力保留为后续候选，不以缩减一期方式删除历史编号。前端、后端和后台任务必须共享相同事实与规则。

## 状态、隐私与恢复

本人数据和导出需认证。新增/修改需明确反馈，失败不覆盖旧有效结果。归档与删除语义按上述规则执行；源数据修订与用户记录版本分离。日志和导出不得包含密钥，外部文本不构成可执行指令。

## 待评审与交接

本稿功能范围和产品建议值待用户确认；数据源实际覆盖、部署配置和性能目标待验证。不得把这些待确认事项改写为已通过。确认后同版本详设应逐条映射规则与验收，不得绕过需求新增自动交易、付费来源或外部通知。
