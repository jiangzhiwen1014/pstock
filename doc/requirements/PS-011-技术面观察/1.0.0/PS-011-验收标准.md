# PS-011 技术面观察 验收标准

需求独立版本：1.0.0。交付批次：V1.0.0。状态：待评审/未执行。

## 场景清单

以下每项都需要实际操作/接口结果及数据证据，不能仅凭截图或模型回答判定成功。使用固定测试数据，账户样本不包含真实凭据。

| 验收 ID | 关联规则 | 操作及数据条件 | 预期结果 |
|---|---|---|---|
| PS-011-AC01 | PS-011-R01 | 切换未复权/前复权与时间范围，并核对持仓使用价格 | 同一图切换口径后指标与曲线口径一致，持仓估值仍按未复权价。 |
| PS-011-AC02 | PS-011-R02 | 在固定版本样本上重复计算并检查参数说明 | 同一数据/参数版本反复计算一致；页面能查看参数含义。 |
| PS-011-AC03 | PS-011-R03 | 分别提供20、21个收盘样本以及中间缺行情样本 | 仅20个收盘值时MA20可算但20日涨跌幅不可算；缺中间应有行情时标记数据缺口。 |
| PS-011-AC04 | PS-011-R04 | 以[10,12,9]验算公式，再检查59/60样本正式窗口 | 样本[10,12,9]用于公式验算得到25%回撤；正式窗口不足60时显示样本不足。 |
| PS-011-AC05 | PS-011-R05 | 分别输入已知停牌和未知原因缺行情 | 停牌跨多日后用户能看出跨度，接口失败不会变成连续横盘K线。 |
| PS-011-AC06 | PS-011-R06 | 对不同量级股票/基准归一化，再移除部分基准数据 | 不同价格量级归一化后起点一致，基准缺失时仍保留个股图并提示。 |
| PS-011-AC07 | PS-011-R07 | 构造收盘高于MA20的样本并检查状态与数值 | 价格条件成立时展示数值依据，没有来源的买入/卖出命令不会出现。 |
| PS-011-AC08 | PS-011-R08 | 输入盘后公告；快速切换两只股票并延迟旧请求 | 盘后公告清楚显示盘后发布；切换股票时旧请求不能覆盖当前股票图。 |
