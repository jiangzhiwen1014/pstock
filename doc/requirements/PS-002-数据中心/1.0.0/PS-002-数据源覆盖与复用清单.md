## 源码检查已确认的适配事项

以下结论来自上述固定提交的静态检查，不等于接口实测：

- eastmoney_datacenter固定pageNumber=1，cninfo_announcements固定pageNum=1；使用它们的取数任务须补分页、终止条件和覆盖核对，不能只调大page_size就认为全量完成。
- _cninfo_ts_to_date把时间转为日期字符串，且使用运行环境默认时区。PStock需保留原始时间及其精度，明确Asia/Shanghai转换；如无法核实精确发布时间，标为未知而非补零点。
- sina_financial_report默认仅最近8期，财务数值保留为源字符串。须分别验收5份年度记录与8个季度、数值单位及披露口径，不能由参数名推断覆盖。
- eastmoney_stock_news对content取前200字符，eastmoney_global_news对summary取前200字符；摘要不代表全文。F10示例中的print(text[:200])属于显示截短，也不能照抄为完整原文存储策略。
- 北交所官方备选bse_quote_backup提供当前快照，上游整合记录明确无历史回填；BaoStock历史估值和新浪复权也存在北交所边界。补充来源验证属于一期全A目标的实际工作，不能以快照代替历史。
- norm_ticker和市场路由等辅助函数需与调用方一起检查；输出代码不能丢失证券身份。同名、前后缀、当前/历史代码和指数/股票歧义需专门验证。

## 能力登记与启用标准

每项能力至少登记：本清单ID、真实供应方/端点、许可或允许用法核查、上游提交与函数、PStock适配版本、支持市场和字段、历史区间、时间精度/时区、价格/财务/数量口径、分页与调用限制、主备来源及是否独立、验证日期/环境/证据、就绪状态及缺口处理。

源码已引入、待适配、待验证、已验证可用是不同阶段；已验证后发生故障或停用也须保留最后有效结果和状态。接口存在、HTTP200、空列表、上游测试通过都不能独立成为“已验证可用”的依据。

启用前按能力涉及范围验证：

1. 在声明支持的每个板块至少保留一个真实样本；另选新上市、停牌、更名换码、金融企业及历史不足等适用边界样本。只对涉及该能力的情况验证，不假造当前存在的特殊状态公司。
2. 超过一页的数据核对总数和期次；覆盖采集中断、重复采集、解析失败及来源切换。时间/单位/复权检查必须比对原始证据。
3. 本地验证与目标云环境验证分别记录；云端未验证时不宣称具备生产可达或稳定采集能力。4核4G全量容量另按V1-G06验收。
4. 样本通过只证明记录的能力边界；全A公司目录仍按固定基准名单100%核对，实际历史和字段完整度逐类统计。
5. 必需核心能力存在可得缺口时继续补齐并重新验证；来源确不可得时提交缺口及方案评审。不得自行缩减全A目标、把待采集改写为未披露或标记整项完成。
