## 目标与场景

为一期所有页面提供来源明确、时间可查、缺失可见的数据，避免多个模块对同一事实各算一套。

## 主流程

配置数据集与允许来源 → 首次分批补齐 → 校验标准化 → 保存来源与版本 → 生成分析就绪状态 → 定时增量更新 → 失败重试或补采。

入口、跨功能要求及一期容量见 [一期总览](../../V1.0.0-一期需求总览.md)。所有个人投资参数未确认时保持未设置；提到的容量/指标/时刻为产品建议值，不是已知用户事实。

## 数据对象

证券、交易日历、行情、复权信息、财务记录、公告文档、采集任务、来源能力、质量结果；保留事实时间、披露时间、首次可用时间、采集时间、修订版本和单位。

对象字段为业务语义，物理表、接口路径、错误代码和索引由同版本详设确定。来源、质量与版本语义遵守 [数据架构](../../../architecture/数据架构.md)。

## 业务规则

| 规则 ID | 规则 |
|---|---|
| PS-002-R01 | 沪深主板证券基础信息、交易日历及近3年可得日线为首批全量范围；重点公司最多50家（含最多20条持仓的验收样本），采集近5份可得年报、最近8个已披露季度财务、近90天公告和可得近30天新闻。以上是一期建议容量及回补目标，不假定来源完整。 |
| PS-002-R02 | 免费来源优先。公告原文候选为巨潮/交易所，结构化接入候选为 AKShare，历史行情候选为 BaoStock；正式接入须验证允许用法、云端可达、覆盖、单位和调用限制，不将免费网页等同免费批量 API。 |
| PS-002-R03 | 证券以稳定身份绑定市场和板块，更名保留历史别名；不按简称合并公司。日期、币种、数量单位显式转换；保留原始字段，重复数据以来源、业务键和版本处理。 |
| PS-002-R04 | 日线的未复权、前复权和复权因子/版本明确区分；财务明确合并/母公司、累计/单季、报告期与实际披露时间。无披露时间的历史资料不得用于当时已知的判断重建。 |
| PS-002-R05 | 质量状态至少包含正常、缺失、过期、冲突、失败、不适用。数据集按交易日历和来源更新时间判定新鲜度；停牌/未到披露期与失败区分。核心输入缺失则相关计算不可用。 |
| PS-002-R06 | 原始披露保存原文链接、文档身份、获取记录；在来源允许时存档全文并校验内容。扫描件/表格解析失败保留原件入口和待核对状态，不把抽取错误当事实。 |
| PS-002-R07 | 增量采集记录游标并保留重叠窗口去重；任务失败可重试、重启可续跑。接入层与分析层分离，采集频率受来源窗口和限额约束，独立于每日展示频率；只对实际缺失段补采。 |
| PS-002-R08 | 同一字段冲突保留各来源及采用理由；备用来源切换须验证口径。指标必须记录源数据版本；页面展示最近成功更新时间、失败状态与覆盖范围。数据写 PostgreSQL，允许的大文档在仓库外存档并纳入备份。 |

## 正常与异常结果

- PS-002-AC01：新上市公司不足3年时展示实际覆盖；新闻来源只有短窗口时标记缺口，不伪造30天历史。
- PS-002-AC02：某候选需要付费权限时标记未启用，不自动付费；来源验证记录可查到数据集和边界。
- PS-002-AC03：同名不同市场证券不合并；成交量手/股转换后可核对，重复采集不重复增加日线。
- PS-002-AC04：两个季度累计收入不被直接标为单季；后发布更正值不回写旧报告快照。
- PS-002-AC05：周末不会仅因未出现当天日线而报警；有效交易日超过配置宽限仍未更新会显示过期。
- PS-002-AC06：损坏 PDF 或解析失败不发布空财务值；用户可看到失败原因及仍可用的原文链接。
- PS-002-AC07：任务中断重启后从已保存进度继续；最近窗口不足时产生覆盖缺口提示，不声称历史完整。
- PS-002-AC08：主源失败时保留旧有效数据并标明时间；不同供应商复权值不能无说明拼成一条曲线。

这些结果定义预期行为，执行步骤与规则映射见 [验收标准](PS-002-验收标准.md)，当前均未运行。

## 本期边界

一期不承诺免费全市场完整新闻史、全量历史财务修订、逐笔/盘口数据、所有外围市场或无限历史深度。

原方案中超出本期的能力保留为后续候选，不以缩减一期方式删除历史编号。前端、后端和后台任务必须共享相同事实与规则。

## 状态、隐私与恢复

本人数据和导出需认证。新增/修改需明确反馈，失败不覆盖旧有效结果。归档与删除语义按上述规则执行；源数据修订与用户记录版本分离。日志和导出不得包含密钥，外部文本不构成可执行指令。

## 待评审与交接

本稿功能范围和产品建议值待用户确认；数据源实际覆盖、部署配置和性能目标待验证。不得把这些待确认事项改写为已通过。确认后同版本详设应逐条映射规则与验收，不得绕过需求新增自动交易、付费来源或外部通知。
