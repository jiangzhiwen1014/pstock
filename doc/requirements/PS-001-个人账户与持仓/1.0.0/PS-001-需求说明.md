## 目标与场景

让我维护真实持仓的研究快照，知道当前关注对象与组合分布，避免系统按未经确认的资金和风险参数作判断。

## 主流程

创建个人账户 → 填写快照日期、现金和持仓 → 校验并预览 → 确认保存 → 查看估值与集中度 → 后续新增快照并比较。

入口、跨功能要求及一期容量见 [一期总览](../../V1.0.0-一期需求总览.md)。所有个人投资参数未确认时保持未设置；提到的容量/指标/时刻为产品建议值，不是已知用户事实。

## 数据对象

账户 ID、快照 ID/日期/版本、证券 ID、持有数量、用户填报的成本单价、现金、备注、来源标记、更新时间；每项估值记录价格日期与口径。

对象字段为业务语义，物理表、接口路径、错误代码和索引由同版本详设确定。来源、质量与版本语义遵守 [数据架构](../../../architecture/数据架构.md)。

## 业务规则

| 规则 ID | 规则 |
|---|---|
| PS-001-R01 | 提供一个个人真实账户，允许无持仓开始；一期手工录入及编辑快照，不连接券商、不提供自动交易。资金规模、持有周期和风险阈值默认未设置。 |
| PS-001-R02 | 数量必须为正，成本单价可为空但不能为负；成本为零须明确确认为用户填报的零成本；现金可为空但不能为负。保存前列出逐项错误，任何错误均不部分保存。 |
| PS-001-R03 | 同一快照同一证券只保留一条汇总持仓，重复行要求用户合并后确认。数量单位统一为股，不因不足整手而拒绝合法历史持仓；不把当前交易单位规则用于快照录入。 |
| PS-001-R04 | 持仓市值=数量×最近有效未复权收盘价；估算浮动盈亏=(同一价格−用户成本单价)×数量。成本口径显示为用户填报，不声称等于券商可对账收益；不计算历史已实现收益。 |
| PS-001-R05 | 已知总资产=现金与完整持仓估值之和；任一价格缺失或现金未知时，总资产标记不完整，并单独列已知部分。股票集中度分母为完整股票市值，排除现金；行业未知单列。 |
| PS-001-R06 | 修改生成新快照版本，历史保持可查；误录通过新版本纠正。移除某项持仓只影响新快照，不删除研究、消息和判断历史；重复提交同一保存操作不生成两份。 |
| PS-001-R07 | 只能把已识别且有交易权限的沪深主板证券录入真实持仓；外围或身份不明证券保留研究入口但不能混入持仓。停牌或风险状态不隐瞒，价格显示截至时间。 |
| PS-001-R08 | 本期不自动扣减现金、记模拟成交、计算税费或处理公司行动；分红送转等事件关联提示用户核对并更新快照。提供快照历史浏览与结构化导出，导出只限已登录本人。 |

## 正常与异常结果

- PS-001-AC01：新用户不录入资金也能研究公司，系统不生成默认本金或风险承受值。
- PS-001-AC02：输入负数量或负现金时拒绝整次保存；成本留空可保存并显示未知，不能按零计算。
- PS-001-AC03：同一证券出现两行时提示冲突；用户合并后只出现一条，少量零股可记录。
- PS-001-AC04：数量100、成本10、有效价12时市值1200、估算浮盈200；成本缺失时只显示市值。
- PS-001-AC05：一只股票无价格时不展示貌似完整的总资产或集中度；行业缺失时出现未知行业分类。
- PS-001-AC06：保存后修改数量，再查看旧报告仍引用旧数量；双击提交仅形成一次保存结果。
- PS-001-AC07：外围参考证券录入被拒绝并说明原因；停牌主板历史持仓可维护且显示价格日期。
- PS-001-AC08：公司送转事件不会自动改数量或现金，用户确认后生成新快照；未登录不能下载账户记录。

这些结果定义预期行为，执行步骤与规则映射见 [验收标准](PS-001-验收标准.md)，当前均未运行。

## 本期边界

券商同步、CSV 导入、交易批次账本、自动公司行动、历史收益归因和税后计算留给独立后续版本。当前快照不是完整交易账本的替代。

原方案中超出本期的能力保留为后续候选，不以缩减一期方式删除历史编号。前端、后端和后台任务必须共享相同事实与规则。

## 状态、隐私与恢复

本人数据和导出需认证。新增/修改需明确反馈，失败不覆盖旧有效结果。归档与删除语义按上述规则执行；源数据修订与用户记录版本分离。日志和导出不得包含密钥，外部文本不构成可执行指令。

## 待评审与交接

本稿功能范围和产品建议值待用户确认；数据源实际覆盖、部署配置和性能目标待验证。不得把这些待确认事项改写为已通过。确认后同版本详设应逐条映射规则与验收，不得绕过需求新增自动交易、付费来源或外部通知。
