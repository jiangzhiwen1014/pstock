# PS-001 个人账户与持仓 验收标准

需求独立版本：1.0.0。交付批次：V1.0.0。状态：待评审/未执行。

## 场景清单

以下每项都需要实际操作/接口结果及数据证据，不能仅凭截图或模型回答判定成功。使用固定测试数据，账户样本不包含真实凭据。

| 验收 ID | 关联规则 | 操作及数据条件 | 预期结果 |
|---|---|---|---|
| PS-001-AC01 | PS-001-R01 | 新建用户，不填资金/风险参数，直接打开公司研究 | 新用户不录入资金也能研究公司，系统不生成默认本金或风险承受值。 |
| PS-001-AC02 | PS-001-R02 | 依次提交负数量、负现金、空成本以及确认零成本的快照 | 输入负数量或负现金时拒绝整次保存；成本留空可保存并显示未知，不能按零计算。 |
| PS-001-AC03 | PS-001-R03 | 同一股票录入两行后尝试保存，再合并为一条含零股的持仓 | 同一证券出现两行时提示冲突；用户合并后只出现一条，少量零股可记录。 |
| PS-001-AC04 | PS-001-R04 | 填数量100、成本10并提供未复权收盘价12，再清空成本 | 数量100、成本10、有效价12时市值1200、估算浮盈200；成本缺失时只显示市值。 |
| PS-001-AC05 | PS-001-R05 | 构造一只无报价股票和一只行业未知股票，分别查看汇总 | 一只股票无价格时不展示貌似完整的总资产或集中度；行业缺失时出现未知行业分类。 |
| PS-001-AC06 | PS-001-R06 | 双击保存后修改数量，再打开修改前报告引用的快照 | 保存后修改数量，再查看旧报告仍引用旧数量；双击提交仅形成一次保存结果。 |
| PS-001-AC07 | PS-001-R07 | 尝试录入海外参考证券，再录入停牌主板历史持仓 | 外围参考证券录入被拒绝并说明原因；停牌主板历史持仓可维护且显示价格日期。 |
| PS-001-AC08 | PS-001-R08 | 注入送转公告，核对账户前后值，再以未登录状态导出 | 公司送转事件不会自动改数量或现金，用户确认后生成新快照；未登录不能下载账户记录。 |
