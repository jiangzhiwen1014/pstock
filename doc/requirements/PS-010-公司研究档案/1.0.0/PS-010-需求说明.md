## 目标与场景

让我理解公司怎样赚钱、经营质量如何、潜在风险在哪里，并能核对每项分析的证据。

## 主流程

打开公司 → 查看经营概览和财务趋势 → 查阅原文 → 选择同行 → 查看支持/反对证据 → 维护外围关联 → 保存研究版本。

入口、跨功能要求及一期容量见 [一期总览](../../V1.0.0-一期需求总览.md)。所有个人投资参数未确认时保持未设置；提到的容量/指标/时刻为产品建议值，不是已知用户事实。

## 数据对象

研究档案/版本、财务快照、原文引用/页码或段落、同行集合、公司表述、研究推断、影响关联/有效期、人工核对状态。

对象字段为业务语义，物理表、接口路径、错误代码和索引由同版本详设确定。来源、质量与版本语义遵守 [数据架构](../../../architecture/数据架构.md)。

## 业务规则

| 规则 ID | 规则 |
|---|---|
| PS-010-R01 | 公司概览展示主营业务、收入构成、行业及披露日期；没有产品/地区构成时明确未披露，不由模型补造。 |
| PS-010-R02 | 财务视图覆盖营收、归母净利、经营现金流、毛利率、研发投入、应收、存货、负债和现金；指标按企业类型处理，不适用于金融企业的指标显示不适用。 |
| PS-010-R03 | 展示近5份可得年报和最近8个季度的趋势；同期比较使用同一口径。季度现金流/利润若由累计值相减得到需明确标记派生；不能跨年度直接相减。 |
| PS-010-R04 | 同行由用户选择并确认，一期最多5家；展示选择理由、行业/业务差异和可比报告期。默认候选只作为建议，不自动认定同概念等于同行。 |
| PS-010-R05 | 研究分为公开事实、公司表述、程序计算、模型推断和用户判断；支持/反对证据均可引用，推断没有有效引用则标记证据不足。公司能力不压缩为一个不透明总分。 |
| PS-010-R06 | 风险卡覆盖资料中已识别的债务、担保、诉讼、审计与经营变化，分别列事实、影响假设和待观察事项；未发现风险只表示当前已覆盖材料未识别，不等于没有风险。 |
| PS-010-R07 | 外围关联由用户确认：外部对象→行业/公司，含传导依据、方向可能性、观察期、反证及失效条件。初期支持手工建立/编辑/失效，不自动构造全市场产业链。 |
| PS-010-R08 | 新资料生成新研究版本和差异，旧版本保留；生成失败保留上一份有效研究，显示时间。模型不可用时仍提供结构化财务、原文及人工笔记；一期不自动OCR全市场档案。 |

## 正常与异常结果

- PS-010-AC01：源年报未披露客户名称时，公司卡不会出现模型猜测的客户。
- PS-010-AC02：银行不套用制造业毛利率/存货结论；原值、单位与报告期能回查。
- PS-010-AC03：半年累计100、一季度40时第二季度派生值60且标明来源；缺第一季度时显示无法派生。
- PS-010-AC04：同行报告期不同时给出不可直接比较提示，不输出统一排名。
- PS-010-AC05：删除或失效引用后相应推断显示待核对；有竞争优势表述但无证据时不能标为已验证。
- PS-010-AC06：公告来源中断时不能显示全面无风险；每项风险有出处与时间。
- PS-010-AC07：铜价与公司成本关系仅按已登记证据提示，系统不把相关性写成确定因果或自动加分。
- PS-010-AC08：模型调用失败时用户仍能查看财报与旧研究；旧研究不会被空结果覆盖。

这些结果定义预期行为，执行步骤与规则映射见 [验收标准](PS-010-验收标准.md)，当前均未运行。

## 本期边界

完整供应链图谱、自动竞争力评级、精确目标价、卖方一致预期库与无限制研报全文抓取不纳入一期。

原方案中超出本期的能力保留为后续候选，不以缩减一期方式删除历史编号。前端、后端和后台任务必须共享相同事实与规则。

## 状态、隐私与恢复

本人数据和导出需认证。新增/修改需明确反馈，失败不覆盖旧有效结果。归档与删除语义按上述规则执行；源数据修订与用户记录版本分离。日志和导出不得包含密钥，外部文本不构成可执行指令。

## 待评审与交接

本稿功能范围和产品建议值待用户确认；数据源实际覆盖、部署配置和性能目标待验证。不得把这些待确认事项改写为已通过。确认后同版本详设应逐条映射规则与验收，不得绕过需求新增自动交易、付费来源或外部通知。
