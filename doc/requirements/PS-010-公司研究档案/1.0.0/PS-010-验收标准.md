# PS-010 公司研究档案 验收标准

需求独立版本：1.0.0。交付批次：V1.0.0。状态：待评审/未执行。

## 场景清单

以下每项都需要实际操作/接口结果及数据证据，不能仅凭截图或模型回答判定成功。使用固定测试数据，账户样本不包含真实凭据。

| 验收 ID | 关联规则 | 操作及数据条件 | 预期结果 |
|---|---|---|---|
| PS-010-AC01 | PS-010-R01 | 打开缺少客户名称、产品构成的公司档案并生成研究 | 源年报未披露客户名称时，公司卡不会出现模型猜测的客户。 |
| PS-010-AC02 | PS-010-R02 | 选择银行和制造业公司对照财务字段和单位 | 银行不套用制造业毛利率/存货结论；原值、单位与报告期能回查。 |
| PS-010-AC03 | PS-010-R03 | 提供一季度40、半年累计100，再删除一季度数据 | 半年累计100、一季度40时第二季度派生值60且标明来源；缺第一季度时显示无法派生。 |
| PS-010-AC04 | PS-010-R04 | 选择报告期不同的两家同行并查看比较 | 同行报告期不同时给出不可直接比较提示，不输出统一排名。 |
| PS-010-AC05 | PS-010-R05 | 向研究输入未附证据的优势表述，再使一条引用失效 | 删除或失效引用后相应推断显示待核对；有竞争优势表述但无证据时不能标为已验证。 |
| PS-010-AC06 | PS-010-R06 | 制造公告来源中断及一条带出处的风险事项 | 公告来源中断时不能显示全面无风险；每项风险有出处与时间。 |
| PS-010-AC07 | PS-010-R07 | 手动登记铜价成本关联与失效条件，再输入铜价变化 | 铜价与公司成本关系仅按已登记证据提示，系统不把相关性写成确定因果或自动加分。 |
| PS-010-AC08 | PS-010-R08 | 生成研究后停用模型，导入财报修订并查看历史 | 模型调用失败时用户仍能查看财报与旧研究；旧研究不会被空结果覆盖。 |

## 共性与集成

还必须满足 [一期总览](../../V1.0.0-一期需求总览.md) 的 V1-G01 至 V1-G12 及相关 E2E 流程。来源失败、模型不可用、未登录、重复提交与历史版本至少各保留一项实际证据。涉及数据库锁、幂等与迁移的实现验证必须使用实际 PostgreSQL；纯计算使用固定可复现样本。

执行记录须包含测试输入、预期/实际、通过/失败、失败原因、执行版本和证据路径。当前没有应用，全部未执行；本次文档校验不计为上述业务验收。
