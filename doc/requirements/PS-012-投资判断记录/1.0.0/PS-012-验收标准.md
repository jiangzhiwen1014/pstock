# PS-012 投资判断记录 验收标准

需求独立版本：1.0.0。交付批次：V1.0.0。状态：待评审/未执行。

## 场景清单

以下每项都需要实际操作/接口结果及数据证据，不能仅凭截图或模型回答判定成功。使用固定测试数据，账户样本不包含真实凭据。

| 验收 ID | 关联规则 | 操作及数据条件 | 预期结果 |
|---|---|---|---|
| PS-012-AC01 | PS-012-R01 | 在持有理由卡上关联负面消息，查看持仓与卡状态 | 系统发现负面事件后创建复核提示，原持仓数量和用户判断状态不被擅改。 |
| PS-012-AC02 | PS-012-R02 | 分别保存无理由、有理由无反证、未设期限的判断 | 无理由时不能保存；没有反对证据时保存成功但显示尚未补充反证。 |
| PS-012-AC03 | PS-012-R03 | 保存卡后更正财务并更新持仓，回读旧卡 | 修改持仓或财报更正后，旧卡仍能显示当时快照。 |
| PS-012-AC04 | PS-012-R04 | 加入仅行业相关消息，检查待复核线索与理由 | 消息仅提同一行业时说明间接关联，不能直接标为公司原假设失效。 |
| PS-012-AC05 | PS-012-R05 | 设置观察到期，延期并填写证据不足 | 期限到达后显示待复核，延期保留原期限与修改原因。 |
| PS-012-AC06 | PS-012-R06 | 两页面编辑同一旧版，依次提交并双击一次保存 | 两个页面同时编辑，后保存者得到冲突提示；双击不会增加两个相同版本。 |
| PS-012-AC07 | PS-012-R07 | 提供价格上涨但经营假设无证据的复盘材料 | 股价上涨但经营假设未验证时仍可标记证据不足，没有自动成功标签。 |
| PS-012-AC08 | PS-012-R08 | 归档再恢复判断，并使原文链接失效，尝试未登录导出 | 归档卡在旧报告中仍可查看；原文失效显示无法访问及保存的来源信息。 |

## 共性与集成

执行记录须包含测试输入、预期/实际、通过/失败、失败原因、执行版本和证据路径。当前没有应用，全部未执行；本次文档校验不计为上述业务验收。
