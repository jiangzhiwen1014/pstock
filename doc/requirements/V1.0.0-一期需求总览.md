## 2. 一期要解决的问题

每天能够知道：哪些相关事实发生变化；公司经营和走势如何；哪些原有判断需要复核；下一步需要观察什么；过去的判断能否被当时的材料解释。

完整使用链：建立关注/持仓 → 数据进入并标注质量 → 公司与技术研究 → 事件关联 → 用户记录判断 → 每日简报 → 后续复核。可以没有持仓或没有模型服务，仍能使用事实资料与人工记录。

成功标准是信息可核对、变化可解释、操作不丢失、历史可回看；不将盈利、上涨概率或每日必须推荐股票作为验收条件。

## 6. 三条端到端业务流程

### E2E-01 建立第一份研究记录

新用户登录 → 添加主板关注 → 采集并显示覆盖 → 查看公司资料和日线 → 记录关注理由及待观察事项 → 保存判断卡 → 查看今日简报。

验收：无需填报本金和风险阈值即可完成；关注、公司、判断、报告关联同一证券；每项数字有口径和时间；无模型时仍能完成。

### E2E-02 新消息影响持仓判断

维护持仓快照和买入理由 → 新公告入库 → 多篇转述归并 → 关联公司与判断 → 报告展示事实和待复核理由 → 用户记录支持、削弱或证据不足。

验收：原文可打开；同一事件不计为多个独立利好；系统不自动修改持仓/现金或替用户决定交易；旧判断仍然可查。

### E2E-03 失败恢复及历史对照

采集/分析中断 → 页面显示失败和旧有效数据 → 重启并续跑 → 补齐形成新版本 → 对照新旧研究和报告。

验收：无重复日线、重复快照和重复站内事件；失败不等于没有消息；旧报告的数据、来源和判断不会被最新修订覆盖。
