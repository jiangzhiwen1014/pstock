# ADR-001 目录与独立需求版本

## 取舍与回退

与全局技术分层相比，业务优先减少单需求跨目录寻找代码，但需要明确模块公开接口，防止跨模块数据库耦合。

独立需求版本便于各自推进，但必须记录明确依赖版本；未来发布时可增加组合清单，不能用需求版本冒充产品版本。
