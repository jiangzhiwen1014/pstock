# ADR-002 前端技术框架

状态：已采纳前端基线；行情主引擎为初选，精确版本与接口/部署细节待确认。依据：用户审阅本会话方案后，明确要求落成文档。

## 背景与选择

PStock 需要大量行情及研究图表、账户表格、信息跟踪和决策证据，采用电脑端优先的单页工作台与独立后端。

选择 React + 严格 TypeScript + Vite + React Router；Ant Design 为基础组件；CSS Modules 与设计变量管理样式。TanStack Query 管理服务端数据，Zustand 仅按需管理共享界面状态。Vitest、React Testing Library 与 Playwright 分别承担逻辑、组件和浏览器验证。

综合图表使用 ECharts；行情图初选 Lightweight Charts，KLineChart 在画线和内置指标需求明确后对比验证。完整职责、目录、任务与边界见 [前端技术框架](../前端架构.md)。

## 备选与代价

- Vue 同样能够构建图表工作台；本次采纳 React 不代表已证明它的图表性能优于 Vue。
- 采用 Vite 单页路线，需要维护路由、数据缓存、错误和拆包的组合。服务端渲染仅在出现明确需求后重新评估。
- Ant Design 提供基础交互，投研布局与金融展示仍需自行设计；暂不引入第二套基础组件库。
- 单用 ECharts 能统一引擎，但复杂行情交互需要额外开发，因此将金融图与综合图分开。
- 两套图表增加封装和联动成本，统一主题/时间/数据输入，保留各自特性。
- Query 与 Zustand 的职责必须明确，避免重复缓存和账户切换串数据。

## 落地与回退

本次只更新文档与 Skill 引用，没有安装或运行前端。首次搭建前确认兼容版本、运行工具、行情主引擎与后端契约。若候选验证失败，在引擎适配层替换并用固定样本核对；若架构基线改变，追加决策，不改写原始已确认含义。

需求独立版本不因技术决策自动升级。后续正式实施以具体需求/详设或已批准基础工程任务为依据。
