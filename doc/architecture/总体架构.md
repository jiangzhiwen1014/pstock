# 总体架构

状态：组织结构已确认，技术实现待选型。

PStock 使用单仓库：统一前端工作台、模块化后端、共享业务规则的 API 与后台任务入口。按业务模块组织代码，外部开源能力通过接入层使用。

业务闭环：新信息 → 质量检查 → 公司/外围研究 → 投资理由与组合风险评估 → 行动条件 → 用户记录 → 持续复盘。模块职责见 [模块边界](模块边界.md)。

## 架构约束

- 系统拥有统一证券身份、数据语义、账户规则与决策记录。
- 真实、模拟、回测账户共享计算定义，持久记录按账户类型、账户 ID 或运行 ID 隔离。
- 用户作最终投资决定；模型提供解释与摘要，数值由可复现的程序计算。
- 开源底座、自建路线、正式回测引擎与数据库均未定案。候选接入不能自行扩大交易权限或形成第二套账本。
- 暂不拆为大量独立服务。后续容量、恢复和部署证据支持拆分时，用架构决策记录说明。
- 投资规模、周期、风险阈值保持未设置，不将历史示例值当用户配置。

选型和正式业务实现前，按 [建设顺序](建设顺序.md) 补齐可验证样本、依赖与许可核验。
