# PStock

面向个人的持续投研与投资决策工作台：统一信息、研究、持仓、风险、交易计划和复盘，围绕自己的交易模式持续提供判断依据。

当前阶段：**目录与架构规划**。本仓库尚未实现应用功能，暂不提供启动命令。

## 项目边界

- 可交易范围：用户已开通权限的沪深主板 A 股。
- 研究范围：其他 A 股板块、海外市场、商品、汇率、利率和宏观事件，用于分析对主板公司及持仓的影响。
- 产品形态：一个 PStock 入口，统一数据、账户、规则版本和决策记录，选择性参考或接入开源组件。
- 决策方式：系统提供事实、证据、条件与风险，由用户做最终决定。
